# Previous-Paper Alignment Map

This note tracks how the current manuscript follows the accepted-paper logic in
`paper/PreviousPapers`. It is an internal writing guide, not submitted paper
text. The closest structural template is AURORA-Q for section rhythm and
ScaleQsim for systems-performance evaluation language.

Count-level evidence is generated by
`scripts/audit_previous_paper_alignment.py` and stored in
`data/processed/perlmutter/previous_paper_alignment_metrics.md`. The metrics
track words, prose paragraphs, bold lead-ins, subsection counts, figure/table
counts, style fingerprints, role-marker order, paragraph-role inventory,
current source-line locations, and previous-paper template source-line
locations.
Block-level trace evidence is generated by
`scripts/audit_previous_paper_deep_trace.py` and stored in
`data/processed/perlmutter/previous_paper_deep_trace.md`; it lists every
meaningful current paragraph, figure, table, equation, and heading with its
source line span and the previous-paper role anchor it follows.
LaTeX idiom evidence is generated by `scripts/audit_previous_paper_style.py`
and stored in `data/processed/perlmutter/previous_paper_style_audit.md`; this
separate audit tracks the accepted-paper `\textbf{}` lead-ins, `subfigure`
environment syntax, caption-before-label order, dense table settings, booktabs,
caption setup, and float spacing.

## Non-Copying Boundary

The manuscript follows the accepted papers' logic and paragraph roles, but it
does not copy their prose. The content is specific to practical quantum-advantage
threshold modeling: native HPC baselines, quantum-circuit application paths,
cuQuantum instrumentation, Perlmutter scaling, and advantage frontiers.
